How is this calculated?

If you are above target (how many can you miss):

We solve: attended ÷ (held + x) ≥ target for the largest whole number x.

x = floor( (attended − target × held) ÷ target )

If you are below target (how many must you attend):

We solve: (attended + x) ÷ (held + x) ≥ target for the smallest whole number x.

x = ceil( (target × held − attended) ÷ (1 − target) )

These formulas assume all future classes are consecutive. The minimum required attendance is set to 75% by most colleges — adjust the slider for your institution's rule.
